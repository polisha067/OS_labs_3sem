# Лабораторная работа №2, вариант 17

Работа с процессами и неименованными каналами (`pipe`) в Linux.

Родитель создаёт два дочерних процесса и передаёт им строки: длиной до 10 символов
включительно - первому, остальные - второму. Дети удаляют русские и английские
гласные обоих регистров и записывают результат каждый в свой файл через
перенаправленный стандартный вывод. Длина считается в символах UTF-8 без `\n`

## Файлы

- `parent.c` - создание процессов, настройка каналов и распределение строк
- `child.c` - удаление гласных; одна программа запускается для обоих детей
- `Makefile` - сборка программ и отчёта
- `report.tex`, `src/`, `styles/`, `inc/` - исходный шаблон отчёта

## Сборка и запуск

Нужны Linux (в том числе Ubuntu в WSL), GCC, Make и локаль `C.UTF-8`
В каталоге репозитория:

```sh
make lab2
./parent
```

Первые две строки ввода - имена двух разных выходных файлов, далее - строки
для обработки. Существующее содержимое выходных файлов перезаписывается
Пример ввода:

```text
first.txt
second.txt
Привет
До свидания Пока
```

Завершение ввода - `Ctrl+D` на пустой строке. В `first.txt` получится `Првт`,
в `second.txt` - `Д свдн Пк`

Удалить собранные программы можно командой `make clean-lab2`
