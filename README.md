# Лабораторная работа №3, вариант 20

Работа с потоками и синхронизацией (`pthread`) в Linux.

Программа находит три точки в пространстве, образующие треугольник максимальной
площади. Потоки берут работу из общего счётчика под мьютексом и хранят свои
максимумы. Результаты объединяются после завершения потоков. При равной площади
выбирается тройка с наименьшими номерами в лексикографическом порядке

## Файлы

- `main.c` - чтение точек, создание потоков и поиск треугольника
- `Makefile` - сборка программы
- `benchmark.c` - генерация данных и замеры ускорения и эффективности

## Сборка и запуск

```sh
make lab3
./lab3 -t 4
```

Ключ `-t` задаёт максимальное число потоков, включая основной. Если рабочих
задач меньше, число потоков уменьшается. Ввод: количество точек (не меньше трёх),
затем координаты `x y z` каждой точки. Координаты конечные, по модулю не больше
`1e75`, чтобы избежать переполнения при вычислении квадрата площади
Пример ввода:

```text
4
0 0 0
4 0 0
0 3 0
0 0 1
```

Результат - точки `2 3 4`, площадь `6.5`. Нумерация точек начинается с 1.
Для точек на одной прямой площадь равна нулю. Время поиска выводится в секундах,
включая создание и ожидание потоков, без чтения входных данных

На большом наборе данных число потоков можно посмотреть во втором терминале
командой `ps -L -p PID` или `top -H -p PID`. PID выводится при запуске программы.
В строке «Поток ... начал работу» указан идентификатор pthread, он может
отличаться от TID в `ps`. Результаты, подсказки и ошибки выводятся по-русски

## Замеры

```sh
make benchmark
./benchmark 3
```

Для каждого размера используются одинаковые точки и медиана времени повторных
запусков. Ускорение считается как `T1 / Tp`, эффективность - как `T1 / (p * Tp)`.
Программа проверяет 200, 500 и 1000 точек при 1, 2 и 4 потоках. Аргумент задаёт
число повторов (по умолчанию 3). Координаты генерируются с начальным состоянием
20; результаты каждого запуска сравниваются с однопоточным. Временные файлы
создаются через `tmpfile` и удаляются при закрытии. Сложность поиска - `O(N^3)`

Удалить собранную программу можно командой `make clean-lab3`
