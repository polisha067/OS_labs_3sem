# Лабораторная работа №4, вариант 17

Обмен данными между процессами через отображаемые в память файлы.

## Файлы

- `parent.c` — родительская программа и распределение строк по длине.
- `child.c` — удаление русских и английских гласных.
- `Makefile` — сборка двух программ.

## Сборка исходной версии

Нужны Linux, GCC, Make и локаль `C.UTF-8`.

```sh
make
./parent
```

Первые две строки ввода — имена разных выходных файлов, затем — текстовые строки.
Завершение ввода — `Ctrl+D` на пустой строке.
Существующее содержимое выходных файлов перезаписывается.

Удаление собранных программ:

```sh
make clean
```
