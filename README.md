# Лабораторная работа №5, вариант 17

Динамические библиотеки на C++

## Файлы

Исходники и `Makefile` находятся в папке `src`

- `contracts.hpp` — объявления функций `PrimeCount` и `Pi`
- `impl1.cpp` — подсчёт простых чисел перебором делителей и вычисление π по ряду Лейбница
- `impl2.cpp` — решето Эратосфена и вычисление π по формуле Валлиса
- `program1.cpp` — программа с подключением первой библиотеки при компоновке
- `program2.cpp` — программа с загрузкой и переключением библиотек во время работы
- `commands.hpp` — обработка общих команд ввода
- `Makefile` — сборка обеих программ и библиотек

## Сборка и запуск

На macOS, если инструменты разработчика ещё не установлены, выполни `xcode-select --install`

```sh
cd src
make lab5
```

Из папки `src` запуск `./program1` или `./program2`. Команды вводятся по одной на строку. Ввод завершается по `Ctrl+D`

- `1 A B` - число простых на отрезке `[A, B]`, где `1 <= A <= B`
- `2 K` — приближение π по `K` членам ряда или множителям произведения, где `K >= 1`
- `0` — переключение между реализациями в `program2`. При запуске активна первая

Пример ввода для `program2`

```text
1 1 10
2 1
0
1 1 10
2 1
```

Вывод программы

```text
4
4
реализация 2
4
2.66667
```

Собранные файлы можно удалить командой `make clean`

## Сравнение способов подключения

При сборке `program1` компоновщик записывает зависимость от `libimpl1`. При запуске системный загрузчик находит библиотеку рядом с программой. В коде можно напрямую вызвать `PrimeCount` и `Pi`. Если библиотека отсутствует, программа не запустится

`program2` открывает библиотеку по относительному пути через `dlopen`, получает адреса функций через `dlsym` и вызывает их через указатели. Команда `0` сначала проверяет, что новая библиотека загрузилась и обе функции найдены, затем закрывает старую через `dlclose`. Если открыть новую библиотеку не удалось, текущая остаётся доступной
